USN Watchbill Generator
=============================

Goal
----------------------------

This project for my Intro to Java class (Fall 2026 Miramar College, taught by Professor Farnaz Dargahi) is meant to be a program that watchbill coordinators in the Navy can use to automatically generate watchbills. 
Ideally this will automate as much of the process as possible and minimize where able the amount of input and record-keeping needed by the watchbill coordinator(s).

## How to use
Create watchbill then use code to make a new one. :)
